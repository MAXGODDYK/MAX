# Табачная смесь для кальяна

В этом репозитории лежит переносимый архив проекта с готовой SQLite-базой `ingredients.db` внутри. Таблица табака в базе очищена, рецепты и справочники сохранены.

## Как развернуть на Windows

1. Скачай репозиторий ZIP-архивом через GitHub или клонируй его.
2. Открой PowerShell в папке репозитория.
3. Выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\restore_project.ps1
```

4. Запусти приложение:

```powershell
.\project\run_app.bat
```

После распаковки проект будет лежать в папке `project/`. Внутри есть приложение `Подбор ингредиентов`, база данных, SQL-схема, стартовые данные, скрипты импорта и генератор документа рецептов.

## Почему проект лежит частями

Текущий GitHub-коннектор не передаёт бинарные файлы напрямую как обычный `git push`, поэтому проект упакован в ZIP и разбит на Base64-части в папке `project_zip_parts/`. Скрипт `restore_project.ps1` автоматически собирает их обратно.

## Состав восстановленного проекта

- `Подбор ингредиентов/app.py` — GUI-приложение.
- `Подбор ингредиентов/ingredients.db` — готовая SQLite-база.
- `Подбор ингредиентов/schema.sql` — схема базы.
- `Подбор ингредиентов/sample_data.sql` — стартовые рецепты и демонстрационные записи.
- `run_app.bat` — запуск приложения.
- `create_desktop_shortcut.ps1` — создание ярлыка на рабочем столе.
- `Точные рецепты/build_recipes_doc.py` — генератор документа рецептов.

## Требования

Для приложения нужен Python 3.11 или новее. Внешние библиотеки для GUI не нужны: используются `tkinter` и `sqlite3` из стандартной поставки Python.
