# Табачная смесь для кальяна: рецепты и калькулятор

Локальный проект для хранения рецептов, ведения базы ингредиентов и расчёта стоимости партии смеси. Проект рассчитан на запуск на обычном Windows-ПК с установленным Python.

## Состав проекта

- `Подбор ингредиентов/` — Python-приложение на `tkinter + sqlite3`.
- `Подбор ингредиентов/ingredients.db` — локальный SQLite-кэш, создаётся на компьютере пользователя и не хранится в GitHub.
- `Подбор ингредиентов/schema.sql` — схема базы.
- `Подбор ингредиентов/sample_data.sql` — стартовые демонстрационные данные и рецепты.
- `Точные рецепты/` — готовые DOCX/PDF с техкартами рецептов и скрипт их пересборки.
- `run_app.bat` — быстрый запуск приложения на Windows.
- `create_desktop_shortcut.ps1` — создание ярлыка на рабочем столе.

## Быстрый запуск

1. Установи Python 3.11 или новее.
2. Скачай или клонируй проект.
3. Запусти файл `run_app.bat`.

Можно запустить вручную:

```powershell
cd "Подбор ингредиентов"
py app.py
```

## Ярлык на рабочий стол

Из корня проекта выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\create_desktop_shortcut.ps1
```

После этого на рабочем столе появится ярлык `Подбор ингредиентов и калькулятор смеси`.

## База данных

Файл `Подбор ингредиентов/ingredients.db` не публикуется в GitHub. Данные живут в Google Таблице, а SQLite используется как локальный кэш на каждом устройстве.

Если `ingredients.db` отсутствует и синхронизация настроена, приложение создаёт пустую локальную базу и при запуске подтягивает данные из Google Таблицы. Если синхронизация не настроена, приложение работает локально и может создать демонстрационные записи.

В базе есть отдельные таблицы для глицерина, табака, ГФС, ароматизаторов, пропиленгликоля и дистиллированной воды. В рецепте можно добавлять несколько строк одного типа, например два разных табака; в калькуляторе товар выбирается отдельно для каждой строки рецепта.

Стартовый каталог содержит 8 рецептов: 3 базовых пересчитаны с 3% дистиллированной воды, ещё 5 добавлены как сборки под Virginia Gold, Virginia, Burley и миксы Virginia+Burley.

Для строк табака в рецепте можно задавать фильтры: вид/классификацию, крепость, нарезку и размер нарезки в мм. Калькулятор показывает только те карточки табака, которые подходят под заполненные фильтры строки.

Локальная база `ingredients.db`, резервные копии вида `ingredients_backup_*.db`, `google_sheets_config.json` и папка `secrets/` не публикуются в GitHub и остаются только на твоём компьютере.

## Зависимости

Для приложения внешние библиотеки не нужны: используются `tkinter` и `sqlite3` из стандартной поставки Python. Для пересборки DOCX-файла с рецептами нужна библиотека `python-docx`:

```powershell
py -m pip install -r requirements.txt
py ".\Точные рецепты\build_recipes_doc.py"
```

## Google Таблицы

Приложение умеет синхронизировать локальную SQLite-базу с одной общей Google Таблицей. SQLite остаётся локальным кэшем, а Google Таблица — общей удалённой копией, которую можно аккуратно редактировать вручную.

1. Создай Google Sheet и скопируй его ID из ссылки.
2. В Google Cloud включи Google Sheets API, создай service account и скачай JSON-ключ.
3. Положи ключ в `secrets/google_service_account.json`.
4. Расшарь Google Sheet на email service account с правом редактирования.
5. Скопируй `google_sheets_config.example.json` в `google_sheets_config.json`, вставь `spreadsheet_id` и поставь `"sync_enabled": true`.
6. Только для первого наполнения пустой Google Таблицы выгрузи текущую локальную базу:

```powershell
py -m pip install -r requirements.txt
py .\setup_google_sheets.py
```

После настройки приложение синхронизируется при запуске, после сохранений/удалений и по кнопке `Синхронизировать сейчас`. Если одну запись изменили и локально, и в Google Таблице, версия из Google Таблицы считается главной.

На новом устройстве не нужен готовый `ingredients.db`: достаточно склонировать проект, создать локальный `google_sheets_config.json`, положить JSON-ключ service account в `secrets/` и запустить приложение. Скрипт настройки и обычная синхронизация сами создают нужные листы Google Таблицы, включая `distilled_water` и `item_packagings`. Названия листов и колонок менять не нужно.
