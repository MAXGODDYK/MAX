# Подбор ингредиентов и калькулятор смеси

Небольшое локальное приложение на Python для ведения базы ингредиентов и расчёта рецептов табачной смеси для кальяна.

## Запуск

```powershell
py app.py
```

При первом запуске рядом с приложением создаётся локальный кэш `ingredients.db`. Если синхронизация с Google Sheets настроена, пустая база сначала заполняется из Google Таблицы. Если синхронизация не настроена, приложение работает локально и может добавить демонстрационные записи из `sample_data.sql`.

## Что есть внутри

- локальный SQLite-кэш с таблицами для глицерина, табака, ГФС, ароматизаторов, пропиленгликоля, дистиллированной воды, фасовок и рецептов;
- синхронизация с общей Google Таблицей, если она настроена в `google_sheets_config.json`;
- вкладки ингредиентов с добавлением, редактированием, удалением, поиском и фильтрами;
- у каждого товара можно вести несколько фасовок, а калькулятор считает стоимость по выбранной фасовке;
- фильтры для табака по классификации и крепости;
- справочники для классификаций, крепости и нарезки табака;
- фильтры для ароматизаторов по типу и вкусу;
- редактор рецептов: проценты должны суммарно давать 100%;
- калькулятор: вводишь нужный общий вес, выбираешь рецепт и товары из базы по каждой строке рецепта, получаешь граммы и стоимость.
- в рецепте можно добавлять несколько строк одного типа, например два разных табака с разными процентами.
- у табачной строки рецепта можно выбрать вид, крепость, нарезку и мм; калькулятор отфильтрует выпадающий список под эту строку.
- стартовые 8 рецептов уже пересчитаны с дистиллированной водой и отдельными сборками под Virginia Gold, Virginia, Burley и миксы.

## Важные правила заполнения

- Название ингредиента обязательно.
- Нужно заполнить хотя бы один источник или контакт: продавец, ссылка, телефон, Telegram, Viber или email.
- Цена может быть пустой. Тогда калькулятор посчитает граммы, но стоимость покажет как неизвестную.
- Цена считается из фасовок товара. В основной строке товара отображается основная фасовка для совместимости.

## Синхронизация с Google Таблицей

Настройка находится в корне проекта: `google_sheets_config.json`. Без этого файла приложение работает локально, а внизу окна показывает `Синхронизация не настроена`.

Файлы `ingredients.db`, `google_sheets_config.json` и папка `secrets/` не должны попадать в GitHub. На новом устройстве создай локальный `google_sheets_config.json`, положи ключ service account в `secrets/google_service_account.json`, и приложение само подтянет данные из общей Google Таблицы.

Если синхронизация включена, приложение:

- скачивает изменения из Google Таблицы при запуске;
- отправляет локальные изменения после сохранения или удаления;
- позволяет запустить обмен кнопкой `Синхронизировать сейчас`;
- сохраняет офлайн-изменения в очереди и отправляет их позже;
- при конфликте применяет версию из Google Таблицы.

Не меняй названия листов и колонок в Google Таблице. Листы `distilled_water` и `item_packagings` создаются автоматически setup-скриптом или следующей синхронизацией. Строки можно редактировать вручную аккуратно; для новых ручных строк лучше оставлять `id` пустым, приложение назначит его при следующей синхронизации.

## Импорт табака с Agro-Ukraine

Для обновления таблицы табака выбранным продавцом Agro-Ukraine:

```powershell
py import_agro_tobacco.py
```

Сейчас скрипт настроен в режиме `IMPORT_ONLY_SPECIAL_SELLER = True`: он удаляет старые записи Agro-Ukraine из таблицы `tobacco` и оставляет только выбранного продавца Михайла из ссылки `m-1354876`. Если в объявлении перечислено несколько видов табака, скрипт создаёт отдельную короткую карточку на каждый вид, например `Virginia - Михайло` или `Burley - Михайло`. Цена вносится как цена за 1000 г для сравнения, но перед покупкой нужно подтвердить фасовку и актуальность у продавца.

Для внесения прайса продавца `Алиса / Табачок` из объявления `m-1125130` и Telegram-прайса:

```powershell
py import_tyt_vsetvoe_price.py
```

Этот импорт добавляет только табаки из прайса, без гильз, бумаги, машинок и аксессуаров. Каждая карточка табака создаётся отдельно: одна классификация и одна крепость на запись, с коротким названием вида `Burley - Алиса / Табачок (средняя)`. Цены берутся из Telegram-прайса за 1 кг; витринная цена на Agro-Ukraine не используется для расчёта.

## Безопасность

Используй только ингредиенты подходящего качества, проверяй назначение, документы и состав. Не используй масляные ароматизаторы. Рецепты и расчёты предназначены для самостоятельных тестов взрослыми пользователями там, где это законно.
